# madhuraghosh.com

Static academic website for Madhura Ghosh.

## Files to upload to GitHub
Upload the contents of this folder to the root of the repository:

- `index.html`
- `styles.css`
- `CNAME`
- `README.md`
- `assets/`

The `CNAME` file is already set to `www.madhuraghosh.com`.

## Preview locally
Double-click `index.html` to open it in a browser.
